## 📋 Quick Start

### Installation
```bash
cd Mirage-Multi-Agent-Orchestrator
npm install
cat > .env << EOF
PINECONE_API_KEY=your_key
GROQ_API_KEY=your_key
EOF
```

### Run
```bash
npm start                    # Auto-detect config
npm start legacyMode.yaml    # Simple sequential
npm start subAgentMode.yaml  # Hierarchical agents
```

### Verify Multi-Session Memory
```bash
npm start spaceResearch-generate.yaml  # Session 1: Generate
npm start spaceResearch-retrieve.yaml  # Session 2: Retrieve
```
